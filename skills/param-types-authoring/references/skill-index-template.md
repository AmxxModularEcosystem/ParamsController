# Шаблон индексного SKILL.md

Заготовка `SKILL.md` для скилла типов параметров плагина. Верхний блок —
frontmatter; он нужен для загрузчиков скиллов. Замени плейсхолдеры.

---

```markdown
---
name: <plugin>-param-types
description: >-
  Типы параметров плагина <Название>: какие JSON-значения допустимы для каждого
  кастомного типа, что контроллер запишет в Trie, какие есть теги и каким
  геттером значение читается. Только специфика типов. Использовать, когда нужно
  заполнить или проверить значение параметра типа <Тип1>, <Тип2>, ...
  Триггеры: <Название>, типы параметров, JSON-параметр, <Тип1>, <Тип2>.
  Use when configuring JSON values for <Название> param types.
---

# Типы параметров <Название>

<Одна строка: что это за скилл.>

Плагин использует ParamsController. Его собственные типы — в `references/`; для
встроенных типов смотри скилл `param-types`. Общие механизмы ParamsController
(теги, чтение, ошибки) здесь не описываются.

## Типы

Файл каждого типа — в `references/`. Открывай только те, что нужны для задачи.

| Тип (имя в конфиге) | Что это | Файл |
|---|---|---|
| `<Тип1>` | <кратко> | `references/<тип1>.md` |
| `<Тип2>` | <кратко> | `references/<тип2>.md` |

## Общее для нескольких типов

<Групповые файлы `references/_<группа>.md` для блоков, которые повторяются у
```

## Подсказки

- `name` во frontmatter делай коротким и уникальным (обычно
  `<plugin>-param-types`).
- В `description` перечисли **имена всех типов** — по ним агент понимает, что
  скилл подходит, и находит его поиском.
- Не дублируй вкладку встроенных типов: одна ссылка на скилл `param-types`.
- Таблица в `SKILL.md` — единственный «указатель» на `references/`; имена
  файлов должны совпадать один в один.
- Групповой файл `references/_<группа>.md` — **только** под реально дублируемый
  блок (один текст на несколько типов, отличается лишь имя типа). Имя свободное,
  по группе/аспекту. Конкретный геттер типа — в его файле, не в групповом.
- Не тащи в скилл общие механизмы ParamsController (теги, чтение, ошибки) — им
  место в общем скилле.
