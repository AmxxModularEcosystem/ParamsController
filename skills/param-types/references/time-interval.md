# TimeInterval

Временной **отрезок** (длительность). В Trie попадает количество секунд.

## Допустимые значения в JSON

**Число** — количество секунд (должно быть `>= 0`):

```json
120
```

**Строка** — последовательность `<число><единица>`:

| Единица | Значение |
|---|---|
| `y` | год = 360 дней (12 × 30) |
| `m` | месяц = 30 дней |
| `d` | день |
| `h` | час |
| `i` | минута |
| _(без буквы)_ | остаток — секунды |

```json
"1d12h30i30"
```

> **`m` — это МЕСЯЦЫ, а не минуты.** Минуты обозначаются `i`.
> Год считается как 360 дней, месяц — 30 дней (не календарные).

Числа и единицы можно писать подряд без разделителей; оставшееся число в конце
строки трактуется как секунды.

## Что получится в Trie

Целое число — секунды.

- `120` → `120`;
- `"1d12h30i30"` → `1×86400 + 12×3600 + 30×60 + 30` = `131430`.

Читается: `PCGet_Int`/`PCGet_Cell`.

## Когда будет ошибка

- число меньше `0`;
- JSON-значение типа boolean/object/array/null.

## Примеры

```json
{
    "VipDuration": "30d",
    "Cooldown": "5i",
    "BanTime": "1y2m3d4h5i6",
    "KickDelay": 60
}
```

- `"30d"` → 30 дней в секундах;
- `"5i"` → 5 минут в секундах.
