# Dir

Путь к **существующей директории**.

## Допустимые значения в JSON

Строка — путь относительно `cstrike/`. Обычно с завершающим слэшем.

```json
"models/player/vip/"
```

## Что получится в Trie

Строка с путём (как указано).

## Когда будет ошибка

- директории по указанному пути нет на сервере;
- значение не строка.

## Примеры

```json
{
    "ModelsDir": "models/player/vip/",
    "LogsDir": "logs/"
}
```

Тип проверяет именно директорию (`dir_exists`), а не файл.
