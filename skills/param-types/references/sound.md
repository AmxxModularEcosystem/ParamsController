# Sound

Путь к **существующему** звуку. При чтении сразу помещается в прекеш
(`precache_sound`).

## Допустимые значения в JSON

Строка — путь **относительно `cstrike/sound/`** (сам префикс `sound/` писать
не нужно, контроллер подставит его для проверки).

```json
"weapon/ak47-1.wav"
```

## Что получится в Trie

- без тега — строка с путём (`"weapon/ak47-1.wav"`, без `sound/`);
- с тегом `Sound:index` — **индекс прекеша** звука (число).

## Когда будет ошибка

- файла `cstrike/sound/<путь>` нет на сервере;
- значение не строка.

## Примеры

```json
{
    "ShotSound": "weapon/ak47-1.wav",
    "VipSound": "vip/hello.wav"
}
```
