# ShortString

Строковое значение длиной до **64 ячеек**.

## Допустимые значения в JSON

Строка. Значение читается через `json_get_string` и обрезается до 64 ячеек
(≈64 латинских символа; кириллица «весит» вдвое).

## Что получится в Trie

Под ключом будет строка.

## Когда будет ошибка

Ошибка возможна при нестроковом JSON-значении, которое нельзя привести к строке.
На практике этот тип всегда используется для текста — пишите строку.

## Примеры

```json
{
    "Name": "ArKaNeMaN",
    "Prefix": "[VIP]"
}
```

Не пишите в `ShortString` длинный текст: всё сверх 64 ячеек будет обрезано.
Для длиннее используйте `String` или `LongString`.
