# Integer

Целое число.

## Допустимые значения в JSON

- **number**: число; берётся как целое.
- **string**: строка читается как число (`str_to_num`) — учитывается ведущая
  числовая часть. `"321"` → `321`, `"12abc"` → `12`.
- **boolean**: `true` → `1`, `false` → `0`.

## Что получится в Trie

Под ключом будет целое число (ячейка).

## Когда будет ошибка

- JSON-значение типа object/array/null.

> Внимание: «плохая» строка **не является ошибкой** — `str_to_num` вернёт `0`.
> Если параметр неожиданно стал `0`, проверьте, что в строке действительно число.

## Примеры

```json
{
    "MaxPlayers": 32,
    "Damage": "25",
    "Multiply": true,
    "Broken": "not-a-number"
}
```

Здесь: `MaxPlayers` → `32`, `Damage` → `25`, `Multiply` → `1`,
`Broken` → `0` (без ошибки чтения).
