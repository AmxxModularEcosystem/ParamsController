# LongString

Строковое значение длиной до **4096 ячеек**.

Используется для заведомо больших текстов (списки, многострочный текст и т.п.).

## Допустимые значения в JSON

Строка. Значение читается через `json_get_string` и обрезается до 4096 ячеек
(≈4096 латинских символов; кириллица «весит» вдвое).

## Что получится в Trie

Под ключом будет строка.

## Когда будет ошибка

Ошибка возможна при нестроковом JSON-значении, которое нельзя привести к строке.

## Примеры

```json
{
    "Rules": "1. Не читерить\n2. Уважать админов\n3. ..."
}
```

> 4096 ячеек — это максимум и для специальных нативов записи строки. Если нужно
> больше, это уже за рамками типов контроллера.
