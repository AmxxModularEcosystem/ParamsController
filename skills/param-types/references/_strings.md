# Строковые типы

Общее для `ShortString`, `String`, `LongString`.

- Значение — строка; лишнее **обрезается** до лимита типа (без ошибки).
- Кириллица «весит» вдвое к числу ячеек.

| Тип | Лимит (ячеек) |
|---|---|
| `ShortString` | 64 |
| `String` | 512 |
| `LongString` | 4096 |

Конкретный формат значения и геттер — в файле типа.
