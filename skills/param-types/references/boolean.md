# Boolean

Логическое значение.

## Допустимые значения в JSON

- **boolean**: `true` / `false`.
- **number**: любое ненулевое число → `true`, `0` → `false`.
- **string** (регистр не важен):
  - истина: `true`, `yes`, `on`, `1`, `y`;
  - ложь: `false`, `no`, `off`, `0`, `n`.

Любая другая строка — **ошибка** (параметр считается некорректным).

## Что получится в Trie

Под ключом будет число: `1` (истина) или `0` (ложь). Читается как `bool`.

## Когда будет ошибка

- строка не из списка выше;
- JSON-значение типа object/array/null.

## Примеры

```json
{
    "Enabled": true,
    "Debug": "off",
    "Count": 2,
    "Flag": "n"
}
```

Здесь: `Enabled` → `1`, `Debug` → `0`, `Count` → `1`, `Flag` → `0`.
