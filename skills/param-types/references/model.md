# Model

Путь к **существующей** модели, которая при чтении сразу помещается в прекеш
(`precache_model`).

> Общее для ресурсных типов (путь/имя, проверка существования) — `_resource-files.md`.

## Допустимые значения в JSON

Строка — путь относительно `cstrike/`. Используйте прямые слэши.

```json
"models/v_ak47.mdl"
```

## Что получится в Trie

- без тега — строка с путём (`"models/v_ak47.mdl"`), читается `PCGet_Str`/`PCGet_iStr`;
- с тегом `Model:index` — **индекс прекеша** модели (число), читается `PCGet_Int`/`PCGet_Cell`.

## Когда будет ошибка

- файла по указанному пути нет на сервере (`file_exists`);
- значение не строка.

> Это самая частая причина «параметр не читается»: путь указан верно, но самой
> модели нет в `cstrike/models/...`.

## Примеры

```json
{
    "ViewModel": "models/v_ak47.mdl",
    "WorldModel": "models/w_ak47.mdl"
}
```

Если параметр объявлен плагином как `Model:index`, в конфиг всё равно пишется
путь — индекс получится в Trie автоматически.
