# Float

Число с плавающей точкой (дробное).

> Общее для числовых типов (разбор числа) — `_numbers.md`.

## Допустимые значения в JSON

- **number**: число (целое или дробное).
- **string**: строка читается как число (`str_to_float`) — `"32.1"` → `32.1`,
  `"12.5abc"` → `12.5`.
- **boolean**: `true` → `1.0`, `false` → `0.0`.

## Что получится в Trie

Под ключом будет число с плавающей точкой (`Float`). Читается: `PCGet_Float`.

## Когда будет ошибка

- JSON-значение типа object/array/null.

> Внимание: «плохая» строка **не является ошибкой** — `str_to_float` вернёт
> `0.0`. Если значение неожиданно нулевое — проверьте строку.

## Примеры

```json
{
    "Damage": 12.5,
    "Speed": "32.1",
    "Ratio": true
}
```

Здесь: `Damage` → `12.5`, `Speed` → `32.1`, `Ratio` → `1.0`.
