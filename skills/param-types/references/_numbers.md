# Числовые типы

Общее для `Integer`, `Float`.

- Принимается JSON-число, строка (читается как число) или boolean
  (`true` → `1`, `false` → `0`).
- Нечисловая строка даёт `0` / `0.0` **без ошибки** — значение не считается
  невалидным.

Точный тип результата (`Integer` — целое, `Float` — с плавающей точкой) и геттер —
в файле типа.
