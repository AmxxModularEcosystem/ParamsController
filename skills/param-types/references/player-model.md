# PlayerModel

Имя (папка) модели игрока. Контроллер сам собирает путь
`models/player/<имя>/<имя>.mdl`, проверяет его и кладёт модель в прекеш.

> Общее для ресурсных типов (путь/имя, проверка существования) — `_resource-files.md`.

## Допустимые значения в JSON

Строка — **только имя модели**, без пути и без расширения, например `"urban"`,
`"gign"`, `"vip"`. Длина — до 64 ячеек.

```json
"urban"
```

Не пишите сюда `"models/player/urban/urban.mdl"` — это другой тип (`Model`) и
здесь такой путь не сработает.

## Что получится в Trie

Строка — исходное имя модели (например, `"urban"`). Читается: `PCGet_Str`/`PCGet_iStr`.

## Что происходит при чтении

1. Проверяется `models/player/<имя>/<имя>.mdl`; если файла нет — **ошибка**.
2. Модель помещается в прекеш.
3. Если рядом есть `<имя>T.mdl` (отдельная T-модель), она тоже прекешится.

## Когда будет ошибка

- нет `models/player/<имя>/<имя>.mdl` на сервере;
- значение не строка.

## Примеры

```json
{
    "VipModel": "vip",
    "DefaultModel": "gign"
}
```
