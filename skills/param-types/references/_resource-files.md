# Ресурсные типы (путь/имя)

Общее для `Model`, `PlayerModel`, `Sound`, `Resource`, `File`, `Dir`.

- Значение — строка: путь к файлу/директории (у `PlayerModel` — имя модели).
- Контроллер **проверяет существование** на сервере. Если файла нет — параметр
  некорректен (значение считается невалидным).
- Пишите прямые слэши.

Базу пути, прекеш, поддерживаемые теги и точный формат значения смотри в файле
конкретного типа.
