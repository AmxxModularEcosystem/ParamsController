# RGB

Цвет — три компоненты: красный, зелёный, синий.

## Допустимые значения в JSON

**Массив** из чисел (берётся до 3 элементов):

```json
[255, 128, 0]
```

**Объект** — короткие или полные имена ключей:

```json
{ "R": 255, "G": 128, "B": 0 }
```

```json
{ "Red": 255, "Green": 128, "Blue": 0 }
```

Если компонента не указана — она считается `0`.

**Строка** — три числа через запятую или пробел:

```json
"255,128,0"
```

```json
"255 128 0"
```

## Что получится в Trie

Массив из трёх целых чисел (`new color[3]`): R, G, B по порядку.
Читается: `PCGet_RGB` (поканально — `PCGet_RGB_Red`/`_Green`/`_Blue`).

## Когда будет ошибка

- строка без запятой и без пробела (`"255"`);
- JSON-значение типа boolean/null.

> Компоненты не ограничиваются диапазоном 0–255 контроллером — числа
> передаются как есть. Некорректная числовая часть превращается в `0`.

## Примеры

```json
{
    "TagColor": [255, 255, 255],
    "MenuColor": { "R": 0, "G": 255, "B": 0 },
    "ChatColor": "255 0 0",
    "Default": { "Red": 255, "Green": 255, "Blue": 255 }
}
```
