# String

Строковое значение длиной до **512 ячеек**.

Это «обычная» строка для основного текста, путей, названий и т.п.

> Общее для строковых типов (лимиты, обрезка) — `_strings.md`.

## Допустимые значения в JSON

Строка. Значение читается через `json_get_string` и обрезается до 512 ячеек
(≈512 латинских символов; кириллица «весит» вдвое).

## Что получится в Trie

Под ключом будет строка. Читается: `PCGet_Str` (или `PCGet_iStr`).

## Когда будет ошибка

Ошибка возможна при нестроковом JSON-значении, которое нельзя привести к строке.
Пишите строку.

## Примеры

```json
{
    "MenuTitle": "Выберите привилегию",
    "ModelPath": "models/player/vip/vip.mdl"
}
```

Если текста больше 512 ячеек — используйте `LongString`.
