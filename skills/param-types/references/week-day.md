# WeekDay

День недели. В Trie попадает **номер дня**: `0` — воскресенье, `6` — суббота.

## Допустимые значения в JSON

Строка, регистр не важен. Принимаются полные и сокращённые названия на русском
и английском:

| № | Значение | Сокращения |
|---|---|---|
| 0 | Воскресенье / Sunday | `Вс`, `Sun` |
| 1 | Понедельник / Monday | `Пн`, `Mon` |
| 2 | Вторник / Tuesday | `Вт`, `Tue` |
| 3 | Среда / Wednesday | `Ср`, `Wed` |
| 4 | Четверг / Thursday | `Чт`, `Thu` |
| 5 | Пятница / Friday | `Пт`, `Fri` |
| 6 | Суббота / Saturday | `Сб`, `Sat` |

```json
"Воскресенье"
```

## Что получится в Trie

Целое число `0..6` (0 = воскресенье).

## Когда будет ошибка

- строка не совпала ни с одним названием из таблицы;
- значение не строка.

## Примеры

```json
{
    "ResetDay": "Пн",
    "EventDay": "Суббота",
    "BackupDay": "Sunday"
}
```
