# Flags

Флаги доступа AMX Mod X, задаваемые строкой. В Trie попадает **битовая сумма**
(маска) указанных флагов.

## Допустимые значения в JSON

Строка из букв флагов, например `"t"`, `"abc"`, `"abcdefghijklmnopqrstu"`.

```json
"t"
```

Буквы — стандартные флаги доступа AMXX (a–z). Конкретный смысл каждой буквы
зависит от стандарта AMXX/сборки сервера; полный список — в документации AMXX
по флагам доступа.

## Что получится в Trie

Целое число — битовая маска (`read_flags`). Например, `"t"` даст одно число,
набор букв — сумму соответствующих битов. Проверяется потом через
`get_user_flags(...) & <маска>`.

## Когда будет ошибка

Обычно не возникает: неизвестные символы просто не дают битов. Если маска
получилась `0`, значит в строке нет валидных флагов.

## Примеры

```json
{
    "RequiredFlags": "t",
    "AdminFlags": "abcdefghijklmnopqrstu"
}
```
