# File

Путь к **существующему файлу** без прекеша.

> Общее для ресурсных типов (путь/имя, проверка существования) — `_resource-files.md`.

## Допустимые значения в JSON

Строка — путь относительно `cstrike/`.

```json
"configs/vip.ini"
```

## Что получится в Trie

Строка с путём (как указано). Читается: `PCGet_Str`/`PCGet_iStr`.

## Когда будет ошибка

- файла по указанному пути нет на сервере;
- значение не строка.

## Примеры

```json
{
    "BanList": "configs/bans.cfg",
    "LogFile": "logs/vip.log"
}
```

Если файл должен ещё и прекешиться (отдаваться клиенту) — используйте
`Resource`. `File` только проверяет наличие.
