# ChatMessage

Строка для вывода в чат. Максимум **190 ячеек** (≈190 латинских символов или
вдвое меньше кириллицы).

## Допустимые значения в JSON

Строка.

```json
"^4Hello ^3world^1!"
```

## Цветовые коды

Вхождения `^1`, `^3`, `^4` превращаются в цветовые управляющие символы движка:

| Код | Цвет |
|---|---|
| `^1` | обычный (белый/по умолчанию) |
| `^3` | цвет команды (обычно синий/зелёный) |
| `^4` | зелёный |

Пишите их прямо в строке — контроллер сам заменит при чтении.

## Что получится в Trie

Строка с уже подставленными цветовыми символами.

## Когда будет ошибка

Обычно не возникает — тип рассчитан на строку. Слишком длинное значение
**обрезается** до 190 ячеек, а не падает с ошибкой.

## Примеры

```json
{
    "Welcome": "^4Добро пожаловать, ^3%s^1!",
    "Prefix": "^3[VIP]^1"
}
```

> Помните про лимит в 190 ячеек: длинная строка с кириллицей может обрезаться
> незаметно. Для визуального текста без цветов используйте `String`/`LongString`.
