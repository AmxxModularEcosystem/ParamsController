# Time

Время **внутри суток**. В Trie попадает количество секунд от полуночи.

## Допустимые значения в JSON

Строка в формате `HH`, `HH:MM` или `HH:MM:SS`:

```json
"6:30"
```

```json
"12:05:25"
```

Часы ограничиваются `0..23`, минуты и секунды — `0..59`.

Число тоже принимается, но **не рекомендуется** (выводится предупреждение), и
трактуется как уже готовое число секунд: `23400` → `23400`.

## Что получится в Trie

Целое число — секунды от начала суток. `"6:30"` → `23400`,
`"12:05:25"` → `43525`.

## Когда будет ошибка

- строка с более чем 3 частями (лишние `:`);
- JSON-значение типа boolean/object/array/null.

Некорректная числовая часть превращается в `0` и ограничивается диапазоном.

## Примеры

```json
{
    "StartAt": "6:30",
    "EndAt": "22:00",
    "DailyReset": "04:00:00"
}
```

Сравнивайте с текущим временем как с секундами от полуночи.
